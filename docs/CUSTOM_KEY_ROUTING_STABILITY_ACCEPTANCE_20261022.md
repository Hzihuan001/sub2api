1. 无响应头的普通网络失败保守禁止自动重放，避免上游已经执行而客户端未收到响应时重复推理、重复费用。插件明确返回类型化 `RequestSent=false` 时允许新尝试；未知插件失败、已发出及已有用量继续禁止重放。

4. 回滚脚本要求显式候选标签与不可变镜像 ID，保留稳定版 custom.12 的原有固定镜像校验。
5. 模拟网关验收补齐 A 真正返回 502 → 同组 B 成功 → B 再返回 502 → 后续分组成功，逐笔及延迟累计核对实际账号、分组、倍率、余额、Key quota、usage 和去重。
