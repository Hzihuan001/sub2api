## 上线范围与结果找回

L1 的指定正式生图账户经内网调用主站。主站校验图片、记录实际尺寸和用量并签发回执。L1 分块暂存、核对字节数和摘要，用自己的定价结算后交付标准 Images API 响应。两站用同一操作 ID 对账。适用入口为非流式 `POST /v1/images/generations` 和 `POST /v1/images/edits`。生图工作台、异步任务、流式与批量生图走原有路径。

调用者可提交 `Idempotency-Key`，超时后使用原 API Key、原幂等键和相同请求重试。响应包含 `X-Image-Operation-Id` 时，也可用原 API Key 查询 `GET /v1/images/operations/{operation_id}`。结果保存 15 分钟。另一把 Key 查询返回 404。同一幂等键的请求内容有变化时返回 409。已保存的计费指令可在重启后继续按原金额结算，原请求结果尚未确定时保留待核对记录，避免上游重复生成。如果进程在结果已落盘、计费指令还未保存时退出，需核对该笔操作的结果文件与账本。

L1 主域名通过延迟 1205 秒的合成 POST 验收。备用域名的健康和页面入口通过，长时间无响应仍受 Cloudflare 约 125 秒的回源读超时限制。 [Cloudflare 524 文档](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-524/)
