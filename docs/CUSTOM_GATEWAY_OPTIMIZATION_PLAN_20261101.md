# 模枢中转站持续优化方案书

## 1. 目标

在保持当前生产行为、数据和计费不变的前提下，持续提升三个方面：

1. 渠道测智页面稳定、安全、加载快，用户只看到分组层面的结果。
2. 定时测试、公共展示、计费对账和长连接出现问题时可定位、可恢复。
3. 定制代码与官方主线保持清晰边界，使下一次版本升级可以用少量适配提交完成合并。

当前生产基线为 `0.2.19-custom.10`。本方案不是重新设计整套系统，而是围绕已上线功能补齐可靠性和维护性缺口。方案评审遵循[定制工作与方案评估准则](CUSTOM_WORKING_PRINCIPLES.md)；具体进度以[计划表](CUSTOM_GATEWAY_OPTIMIZATION_TRACKER_20261101.md)为准。

## 2. 现状判断

已经完成的能力包括：WireGPT 风格渠道测智页面、分组展示顺序、管理端定时测试配置、账号名称隐藏、NULL 租约兼容，以及 Kiro 动态 HTML/SVG 尾部文本修复。三站当前使用同一镜像，容器和健康检查正常。

仍需优先处理的风险是：排序接口的权限策略可能没有与菜单权限完全对齐；测智管理页按账号逐个读取计划，账号量增加后会形成 N+1 请求；服务端对模型返回的 HTML/SVG 仍需在进入浏览器前做完整性和安全约束。之后再处理缓存、任务积压、计费对账、长连接和模块边界。

## 3. 分阶段实施

### 阶段一：正确性和安全（G0–G2）

- 统一排序接口的资源路径和权限映射，补齐角色矩阵测试。
- 为测智管理增加按 `test_kind` 的批量计划读取，保持旧接口兼容，前端优先使用新接口。
- 在服务端建立独立的结果校验器：限制响应大小和处理时间，要求 HTML/SVG 有闭合根节点，拒绝 iframe、表单、外部资源和内联事件处理器；必要时返回安全占位而不是把原始内容直接交给浏览器。
- 保留现有 iframe sandbox 和 CSP，服务端校验作为前置防线，不替换现有展示效果。

阶段验收：后端单元/集成测试、前端类型检查、权限矩阵、恶意/截断 HTML/SVG 样例、三站隔离 Docker 页面检查全部通过。

### 阶段二：性能和任务可靠性（G3–G6）

- 公共测智结果采用短 TTL 缓存，并使用 ETag/304 减少重复响应；结果多时按组分页或懒加载。
- 对 active 计划建立唯一约束或幂等写入；对租约、失败、重试和积压增加指标，后台任务异常不阻断普通 API 请求。
- 测智/监控请求沿用原有计费链路，补充估算成本与实际成本的只读对账，不自动改用户余额、不重复扣费。
- 用隔离环境验证 SSE 首包、心跳、flush、读写超时和 Cloudflare/反代缓冲；将可重试的网络错误与已产生输出的终止区分开，避免重复发送内容。

阶段验收：固定数量并发、长响应、断网恢复、重复提交、租约过期、304 缓存和费用对账场景通过，关键指标有可查询结果。

### 阶段三：主线合并友好化（G7–G8）

- 把测智排序、结果校验、公共缓存和管理端适配放到 custom 目录/服务中；官方 handler、路由和页面只保留稳定接入点。
- 更新 `custom/manifest.yml`、契约检查和升级保护路径，禁止官方核心层反向依赖 custom 细节。
- 固化数据库备份、Compose/环境配置备份、恢复抽检和当前/上一镜像保留规则；增加版本、延迟、失败率、任务积压和发布健康检查记录。

阶段验收：在一个官方新版本候选上完成合并演练，冲突集中在适配层；旧镜像可以启动并完成基本调用；恢复演练不会覆盖上线后的新业务数据。

## 4. 数据与兼容原则

- 不修改已发布迁移，不删除历史业务数据，不用旧数据库覆盖新业务数据。
- 新接口优先兼容旧接口；缓存失效、校验失败、未知状态必须显式记录，不能静默使用错误默认值。
- 测智页面继续按分组展示，不公开账号名称或密钥；后台保留排障所需的请求 ID、错误类别和时间。
- 任何重试或切换不得重复扣费；结果未知时保持待核对状态，不擅自判定成功或失败。

## 5. 发布和回滚

开发完成后依次执行：源码测试 → 隔离 Docker 三站 → 正式镜像回拉复验 → 备份 → 主站 → L1 → COS。每个阶段记录提交、镜像 digest、迁移指纹、健康检查和页面检查结果。

发布过程中出现关键接口失败、页面空白、权限越界、计费差异或容器异常时，停止后续站点，只替换失败站点的应用镜像回到上一 digest；保留新增兼容表，不做破坏性降级。生产变更完成后同步更新项目状态、功能日志和计划表。

## 6. 完成定义

本方案只有在计划表中的事项有对应代码提交、测试证据、部署记录和回滚坐标时才算完成。文档中的“待执行”“已发现问题”“历史”不得在没有新证据时改成“已完成”。
